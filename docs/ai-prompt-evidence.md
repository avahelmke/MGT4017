# AI prototype prompt evidence — ProjectBridge

This file records the prompts used to plan and generate this prototype. For the coursework submission, include screenshots of the actual prompt-and-response conversation from the AI tool you used, alongside screenshots of the running website. This text document is supporting prompt documentation; it is not a screenshot of the AI conversation.

## Prompt 1 — Website structure and audience

"Using my ProjectBridge business model, create a responsive website prototype for a marketplace connecting university students with businesses for short, paid projects. The site must clearly separate the student and business journeys. Include a homepage, About Us, Explore Projects, Pricing Plans, FAQ, Contact & Support and Login."

## Prompt 2 — Student and business functionality

"Add a searchable project directory with category filters for Marketing, Design and Technology. Each project card should show the project title, company, category, work style, duration and payment. Add a project detail view and a student application call-to-action. Include a student sign-up form and a separate business sign-up form."

## Prompt 3 — Dashboard and business workflow concepts

"Design the interface to reflect these workflows: students create profiles, browse and apply for projects, and track applications; businesses create company profiles, post projects, review applications and manage active projects. Include a business project-posting experience as a future-ready part of the product concept."

## Prompt 4 — Visual direction and implementation

"Use the supplied ProjectBridge homepage wireframe and application mock-up as references. Create a clean, modern, professional visual identity with a soft teal and pale blue palette, dark navy typography, rounded cards, clear calls to action and responsive layouts. Use plain HTML, CSS and JavaScript so the prototype can be uploaded directly to GitHub without a build step."
